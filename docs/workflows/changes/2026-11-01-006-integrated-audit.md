## 修改前后

补充跨模块测试：外部线程用量不影响本票据、撤销范围不泄露账目、无报价不能算零、旧快照不能清除已触发上限、worker 不可消耗收尾时段、离线报告不发起工作、记账创建/结束失败不泄漏模型预留，以及源码摘要覆盖 store 等全部包内 Python 代码而不读取私有符号链接。

统筹中补正历史记忆到期日：首次授权范围打开时固定 first_seen + TTL，之后配置变化不延寿，条件写入不覆盖并发数据；删除最新版墓碑保留版本顺序，旧版不回流。原有白名单/冻结身份/独立验证/有限发布恢复/停止确认仍保留。

2026-11-02 跨午夜检查发现，原先 usage 插入/更新、模型预留/退款和发布预留标记分别读取当天，可能写入不同日。本批将预算日固定一次，贯穿用量、调用账本、原生票据与结算；原生环境准备后重读该日余额，避免使用前一日的余额。补充四个确定性跨日回归。此为既有每日额度契约修复，沿用 v0.6，不改变额度或授权。同步仓库内技能和架构/桌面/安全文档，没有升级已安装技能。

## 15 项核对矩阵

| 原问题 | 已实现与证据 | 明确边界 |
| --- | --- | --- |
| 1 Bad case 排查 | 分类错误、持久任务/票据/游标、验证报告、调用溯源；回归覆盖具体故障 | 不把一般质量投诉自动诊断成代码错误 |
| 2 无限工具循环 | 重复、无进展、总步骤；重试仍计数，原生持久 | 只覆盖受监控入口，不覆盖绕过入口的宿主调用 |
| 3 模糊任务 | 不确定则跳过/需要关注，描述/代码反馈分流 | 无通用多轮澄清产品；不自动联系维护者 |
| 4 长链路与成本 | 小工具集、结构化交接、收尾时间预留、观测 token/估价 | 原生遥测可能缺失；模型秒数仍为墙钟预留估计，非账单；无提供方预付硬上限 |
| 5 超时/错误/重试 | 类型/可信 HTTP 分类、安全读取次数/时间/额度、写入不盲重放 | 未知错误不猜瞬时；无通用持久阶段队列/熔断器 |
| 6 工具选择一致性 | 固定控制器路径和阶段工具集；固定轨迹评测 | 没有真实模型重复运行的一致率样本 |
| 7 规划失败 | 固定阶段、小任务、失败保守退出、有限修订 | 没有通用自动重规划策略，不无限替换聊天 |
| 8 长期记忆 | TTL、版本覆盖、失效/删除/审计、墓碑、范围和引用保护 | 不是全盘遗忘或擦盘；已给出的聊天/证据/备份不追溯删除 |
| 9 多 Agent 一致性 | 独立上下文、固定任务包/Handoff、单活动票据与原生终态确认 | 刻意串行，未做分布式多 worker 协调 |
| 10 人工介入 | 异常关注/暂停/通知/确认停止；正常明确任务自主运行 | 无人工接管后台或 SLA，不新增逐 Issue 审批 |
| 11 提示词/模型与注入 | 逐调用精确摘要、请求/观察模型区分、包源码摘要；固定语料与配对报告 | 模型名不是权重版本；原生默认可能未知；未做真实模型/提示词 A/B |
| 12 评价指标 | 14 个固定合成控制案例，分母明确，实际 Docker 验证与可比较环境 | 不是随机真实任务成功率、接受率或模型泛化证明 |
| 13 权限隔离 | Docker 非 root/断网/无凭据；standalone 受限回调，越权中止 | 原生 App 创建接口没有移除宿主工具的参数，Python 不能替它实现 OS 权限边界；未独立安全审计 |
| 14 流式前端 | 原生聊天自身展示；本地状态和离线报告已有 | 未新增自建 SSE/UI，不暴露内部思维链；属于较低优先级产品扩展 |
| 15 通用框架 | 模块分层、依赖注入、模型配置、固定工具协议 | 仍是专用 OSS 控制器，不冒充通用多厂商/规划插件框架 |

原生能力限制来自本会话可用 create_thread 工具的实际 schema：有项目/模型/提示词等字段，没有工具权限剥离选项。本批只检查 schema，没有创建或读取真实修复聊天。受限 standalone 已有，但没有擅自替换主路径或启用 fallback。
