## 问题与预期效果

旧反馈可永久参与检查清单，新版修改没有明确覆盖规则；缺少失效/删除和可追溯治理。删除还需要避免 refresh 复活、删掉新版后旧版复活、导出失败后原文残留，以及跨监控范围误操作。

## 风险与回滚

TTL 为抽取记录有效期，不证明语义事实过期；不同来源的冲突仍需实际证据判断。删除仅作用学习 payload 和已知导出，非全盘遗忘或安全擦除。旧上下文及其他证据可能仍有来源内容。正在使用的记录先拒绝修改，以免制造运行中上下文不一致。

新增表和 JSON 元数据不删除旧任务，但回滚不识别墓碑的代码可能重新抽取已删除反馈；不得清空墓碑后直接恢复旧 heartbeat。先在状态副本演练，并保持停止/预算/processed 记录；无真实状态回滚或回滚提交。
