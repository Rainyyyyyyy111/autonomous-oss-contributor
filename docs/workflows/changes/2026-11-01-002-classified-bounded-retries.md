## 问题与预期效果

v0.3 能限制重复、无进展和总步骤，但错误大多为通用文本，不能统一区分可纠正参数、瞬时读取故障与禁止重放的效果不确定调用。现有发布恢复虽有上限，明确永久错误仍可能被反复恢复。

本批为可信边界增加类型分类，仅对白名单安全读取做有界退避。保护、暂停、期限与共享额度仍优先；不通过重开模型、重跑测试、重复命令或直接重复发布来“提高成功率”。

## 修改前后

| 对象 | 修改前 | 修改后 |
| --- | --- | --- |
| errors / process | 通用异常，命令超时文本 | 控制器异常分类及结构化 ErrorInfo；原 process 导入保留兼容别名 |
| retries / config | 无统一安全读取重试策略 | 最多 3 次调用、每次 5 秒/累计 15 秒、共享 6 次额外尝试、封顶抖动退避 |
| codex / tool_guard / worker_tools | 普通工具错误文本返回 | 参数可纠正；致命错误退出；重试逐次计入工具保护；原生策略/额度持久固定 |
| github | 原始请求失败和限流识别 | 可信状态分类；GET/固定只读 GraphQL/固定 SHA 下载可有限重试；写入不重放，支持 Retry-After HTTP 日期 |
| engine / desktop / notifications / models | 通用失败及发布恢复 | 分类诊断、认证暂停、永久发布错误转关注、已停止任务不被工具重试失败覆写；验证保留分类而不重跑 |
| sandbox / safety | 部分参数与边界错误混合 | 已知参数错误和权限/回归保护明确区分；不会以错误正文授权重试 |

新流程使用 v0.4。保持白名单、运行身份、每日额度、独立验证语义、修订条件、已有发布恢复上限和确认停止要求。无数据库表迁移；没有部署、安装或更新实时配置。

## 风险与回滚

只读期限可能拒绝较慢请求；当前默认是上限而非保证三次都执行。错误类型覆盖已迁移的可信边界，旧通用错误保守视为 unknown。抖动不保证相同等待序列；测试通过注入时钟验证边界。原生额度持久，控制器 GitHub 读取额度仅随适配器实例，不能当作服务全生命周期预算。

未知发布外部效果仍保留有界远端核对；不得因为本地报错就认为写入未发生。失去响应的命令可能仍在容器内执行，因此不重放且保持停止协议。原生宿主绕过、持久化阶段队列、自动重规划、通用熔断器及长期 App 可靠性不在本批完成范围。

回滚本批代码/文档前，先在状态副本核对新增字段兼容；不要覆盖真实账本或清零工具/重试/发布计数。旧配置解析器不接受 limits.retries；本批未修改实际配置。旧版本严格报告/工具状态模型可能拒绝新增 error、last_error 和 retries_used，不能直接回退后恢复生产。已发出的外部效果、已暂停/取消/停止的任务和消耗额度不会因回滚撤销。未创建回滚提交或标签。
