## 问题与预期效果

单元测试数量不能表示 Agent 效果。需要冻结输入/标签、明确统计分母、固定环境、允许候选配对比较，同时避免把模拟 worker 或三个人工选择案例当成模型成功率。

生产验证器被直接复用，源码候选只在 Docker 执行；不访问实际配置/模型/GitHub。基准、oracle、标签和工具权限不来自候选；比较检查环境、样本和重新计算的指标。实际运行报告公开的内容仅为合成案例决策/退出码与摘要，不含真实仓库归档、配置、数据库或原始聊天。

`uv run pytest -q tests/test_evaluation.py`：**7 passed，5.42 秒**；覆盖正确/错误候选、固定语料不可静默改写、环境不可混比、重复案例/伪造指标拒绝、输入大小/链接与 CLI 不加载实际配置。

## 风险与回滚

这仅是合成控制器回归，不测真实模型理解、真实注入服从率或上游接受。模型候选导入不带可信模型归因；配对比较不构成因果或显著性结论。移除 CLI/语料即可撤销离线功能，不需要改实时状态；语料版本与评测报告应保留作历史，不能事后改标签抹去失败。

## 待观察与结果

本批已有上述固定回归结果，但没有真实模型、原生 App 长跑或随机 Issue cohort。未来应独立维护有授权的真实任务/留出集，固定提示词/模型/环境版本并重复运行；不能将本次 14/14 对外转换为 Agent 成功率。
